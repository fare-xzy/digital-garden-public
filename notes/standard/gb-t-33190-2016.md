## 5 概述

GB/T 33190—2016
5 概述
5.1 文档特性
电子文件根据其版面是否固定、是否依赖特定软件或硬件来呈现,可大致分为如下两类:
a) 流式文件:文件内容呈现时的版面随显示环境(如显示器尺寸、字体等)的变化而变化。
b) 版式文件:文件内容呈现时的版面不随显示环境的变化而变化。
本标准所规定的版式文件应具有以下特性:
a) 文档的版面是固定的,在不同的阅读设备上呈现的效果一致;
b) 文档可以包含文字、图形、图像、音频、视频等多种内容;
c) 文档的结构是自包含的,无需引用外部资源即可完整呈现;
d) 文档支持数字签名、电子签章,具有完整性保护机制。
5

GB/T 33190—2016
5.2 结构
OFD 文件采用 ZIP 压缩格式进行组织,文件内部包含 XML 描述文件、字体文件、图像文件、签章文件等多个部分。OFD 文件的总体结构如图 1 所示。
[图 1 OFD 文件结构示意图]
5.3 成像模型
OFD 采用与设备无关的成像模型,主要包含以下基本元素:
a) 页面 (Page):文档的基本组成单位;
b) 图层 (Layer):页面上相互独立的内容层;
c) 图元 (Graphic Unit):图层内的基本绘制对象,如文字、图形、图像;
d) 资源 (Resource):页面引用的字体、图像、颜色等。

## 8 页面描述

### 8.1 坐标系

#### 8.1.1 坐标说明

OFD 坐标系遵循右手笛卡尔坐标系,原点位于页面物理区域的左上角,X 轴向右递增,Y 轴向下递增。

#### 8.1.2 设备空间

设备空间 (Device Space) 是输出设备自身的坐标系,与具体的显示或打印设备相关。

#### 8.1.3 页面空间

页面空间 (Page Space) 是 OFD 文档使用的坐标系,以页面物理区域的左上角为原点,以物理单位(如毫米)为单位。坐标范围由 PhysicalBox 决定。

#### 8.1.4 对象空间

对象空间 (Object Space) 是图元对象自身的坐标系,通过 CTM (Current Transformation Matrix) 转换到页面空间。

#### 8.1.5 变换矩阵

变换矩阵 CTM 是一个 $3 \times 3$ 矩阵:

$$
CTM = \begin{pmatrix} a & b & 0 \\ c & d & 0 \\ e & f & 1 \end{pmatrix}
$$

其中:

- $a, d$ 控制 X/Y 轴方向的缩放
- $b, c$ 控制 X/Y 轴方向的旋转和倾斜
- $e, f$ 控制 X/Y 轴方向的平移

CTM 变换公式 (二维点 $(x, y)$ 变换后为 $(x', y')$):

$$
\begin{cases} x' = a \cdot x + c \cdot y + e \\ y' = b \cdot x + d \cdot y + f \end{cases}
$$

### 8.2.1 绘制参数结构

## 8.3 颜色

### 8.3.1 颜色空间

颜色空间 (Color Space) 表示颜色的一种数学模型。OFD 支持以下颜色空间:

| 颜色空间 | 说明 | 参数 |
|:----:|:----:|:----:|
| DeviceGray | 设备灰度 | 单值 (0~1) |
| DeviceRGB | 设备 RGB | 三值 (R,G,B) 各 0~1 |
| DeviceCMYK | 设备 CMYK | 四值 (C,M,Y,K) 各 0~1 |

### 8.3.2 基本颜色

基本颜色用 6 位十六进制 RGB 表示:

```text
#FF0000   # 红
#00FF00   # 绿
#0000FF   # 蓝
```

### 8.3.3 底纹

底纹 (Pattern) 由 ofd:Pattern 定义,使用固定的图案填充区域。

### 8.3.4 渐变

#### 8.3.4.1 概念和说明

渐变 (Gradient) 用 ofd:GradientShd 节点定义,支持三种渐变类型:轴向渐变、径向渐变、高洛德渐变 (Gouraud)、网格高洛德渐变 (Mesh Gouraud)。

#### 8.3.4.2 轴向渐变 (AxialShd)

```xml
<ofd:Color Value="0 0 255"/>
<ofd:Color Value="255 255 0"/>
```

轴向渐变沿两个点之间的直线进行颜色插值。

#### 8.3.4.3 径向渐变 (RadialShd)

径向渐变以两个圆为边界进行颜色插值,可指定中心点、半径、颜色段。

```xml
<ofd:RadialShd StartPoint="10 70" StartRadius="50"
                EndPoint="10 70" EndRadius="10" Extend="2"/>
```

#### 8.3.4.4 高洛德渐变 (GouraudShd)

高洛德渐变使用三角形网格,在每个顶点上定义颜色,三角形内部进行颜色插值。

#### 8.3.4.5 网格高洛德渐变 (MeshGouraudShd)

网格高洛德渐变是高洛德渐变的扩展,支持任意多边形网格。

## 14 动作

### 14.1 动作描述

动作 (Action) 描述用户交互时文档的响应行为,例如点击链接、提交表单、播放音频等。

动作节点 ofd:Action 包含一个 Event (事件) 和若干 SubActions (子动作)。

```
ofd:Action
├── Event             (触发事件:CLICK / DOC_OPEN / DOC_CLOSE / PAGE_OPEN / PAGE_CLOSE)
├── TriggerObj        (触发对象:链接区域 / 注释 / 全局)
└── SubActions
    └── ofd:SubAction
        ├── Type      (动作类型)
        └── ...
```

事件类型 (Event):

| 事件 | 说明 |
|:----:|:----:|
| CLICK | 鼠标点击 |
| DOC_OPEN | 文档打开时 |
| DOC_CLOSE | 文档关闭时 |
| PAGE_OPEN | 页面打开时 |
| PAGE_CLOSE | 页面关闭时 |

动作类型 (SubAction.Type):

| 类型 | 说明 |
|:----:|:----:|
| Goto | 跳转动作 |
| URI | URI 动作 |
| Sound | 播放音频 |
| Movie | 播放视频 |
| Submit | 提交表单 |
| Reset | 重置表单 |
| ImportData | 导入数据 |
| JavaScript | 执行脚本 |
| Launch | 启动程序 |

### 14.2 跳转动作 (Goto)

跳转到目标位置:

```xml
<ofd:SubAction Type="Goto">
  <ofd:Dest>PageRef=2</ofd:Dest>
</ofd:SubAction>
```

### 14.3 附件动作 (Attach)

加载附件文件。

### 14.4 URI 动作

打开外部链接:

```xml
<ofd:SubAction Type="URI">
  <ofd:URI>https://example.com</ofd:URI>
</ofd:SubAction>
```

### 14.5 播放音频动作

```xml
<ofd:SubAction Type="Sound">
  <ofd:ResourceID>800</ofd:ResourceID>
</ofd:SubAction>
```

### 14.6 播放视频动作

```xml
<ofd:SubAction Type="Movie">
  <ofd:ResourceID>900</ofd:ResourceID>
</ofd:SubAction>
```
